Bring Q Mimi to your desktop

Open Codex when your browser asks. In Codex, choose Install, then Use this pet.

Install in Codex

Requires Codex desktop with pet import support and an internet connection. If the pet is hidden, enter /pet in Codex.

Need help?

Nothing opened? Update Codex desktop and try again. If import is unavailable, see the manual steps in README.en.md.
